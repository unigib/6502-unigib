Seven-segment display

Addresses $00E0-$00EF control 16 digits from left to right. Writing a byte displays its low four bits as a hexadecimal digit from 0 to F. For example, LDA #$0A followed by STA $00E0 displays A in the leftmost digit. Write multiple digits to show a multi-digit value.

Screen pixel addresses

Pixels are stored left to right, then top to bottom. For a pixel at column x and row y (both 0-31), its address is $0200 + (y × 32) + x. The low four bits of the byte select its colour.

Colour values

The four arrow keys write their key codes to $00FF: left 37 ($25), up 38 ($26), right 39 ($27), and down 40 ($28). Each new key replaces the previous value.
Notes: Memory location $fe contains a new random byte on every instruction. Memory location $ff contains the code of the last key pressed. Printable keys use their character code; arrow keys use codes 37 (left), 38 (up), 39 (right), and 40 (down). Memory locations $e0 to $ef control the 16-digit seven-segment display. Each address displays the low four bits of the written byte as one hexadecimal digit, from left to right. Memory locations $200 to $5ff map to the screen pixels. Different values will draw different colour pixels.
