Notes: Memory location $fe contains a new random byte on every instruction. Memory location $ff contains the code of the last key pressed. Printable keys use their character code; arrow keys use codes 37 (left), 38 (up), 39 (right), and 40 (down). Memory locations $200 to $5ff map to the screen pixels. Different values will draw different colour pixels. The colours are: $0: Black $1: White $2: Red $3: Cyan $4: Purple $5: Green $6: Blue $7: Yellow $8: Orange $9: Brown $a: Light red $b: Dark grey $c: Grey $d: Light green $e: Light blue $f: Light grey
